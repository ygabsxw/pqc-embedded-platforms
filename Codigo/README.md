## Dependências

Para compilar e executar os algoritmos deste projeto, algumas dependências externas são necessárias.

### OpenSSL (libssl-dev)

O OpenSSL é utilizado para as implementações de algoritmos de criptografia clássica, como o AES. Para instalar execute:

```bash
sudo apt install libssl-dev
```
